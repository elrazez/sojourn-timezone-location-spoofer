# Phase 06.1: cover the New Tab Page path

The Audit measured the largest Residual Trace: a site opened from Chrome's New Tab Page runs its first script with the real zone, 20 times in 20, because Chrome refuses to attach while its own New Tab Page is showing and the Override can only land after the site commits. A cached document opened in a fresh tab loses the same way, 10 in 10. This phase closes the New Tab Page path by giving Spoofer its own blank New Tab Page: the extension can attach to its own page the moment the tab exists, and Chrome replays the Override into the next document itself.

Start by reading `CLAUDE.md`, `CONTEXT.md`, `docs/plan/00-brief.md` (Residual Traces and the harness rules), every file under `docs/adr/`, `docs/research/chrome-debugger-api.md` (attach rules for extension pages), and `test/e2e/lifecycle.spec.ts` (the skipped New Tab Page and tab-created-onto-url tests). Record `git rev-parse HEAD` as the fixed point.

## Step 1: record the decision

Call the Skill tool with `domain-modeling`. Write `docs/adr/0003-new-tab-page-override.md`: Spoofer declares `chrome_url_overrides.newtab` pointing at a blank extension page so every new tab is attachable before it navigates. Considered Options: the `webNavigation` permission (attaches earlier but still loses to cached documents, and adds a browsing-history warning), a reload after a late attach (the first document has already run, so nothing is unsent), and accepting the gap. Consequences: the user's New Tab Page becomes Spoofer's blank page; the install prompt says so; the remaining gap is a tab created straight onto a URL by a bookmark or an external application when the document comes from cache. Update ADR-0002 with one line: the New Tab Page override is the one manifest capability beyond the two permissions, recorded in ADR-0003. Update the brief's Implementation Decisions (manifest keys) and its Residual Traces list to the narrowed gap, keeping the measured numbers for the case that remains.

## Step 2: slices

Call the Skill tool with `tdd`. Seams are the brief's. Red before green.

1. **Browser**: a tab opened at `chrome://newtab` shows Spoofer's page (title `Spoofer`, no visible controls, no inline script or style) and is Covered within one reconcile tick.
2. **Browser**: from `chrome://newtab`, navigating to the test origin observes `Asia/Tokyo` in its first script, ten times in ten. Unskip and convert the phase 03 New Tab Page test into this assertion.
3. **Browser**: the same flow onto a document served with `Cache-Control: max-age=3600` and already primed in another covered tab, ten in ten, zero server requests.
4. **Browser**: the same flow observes the Selection's point from a `getCurrentPosition` started in the first script, with the 5000 ms timeout.
5. **Reducer**: a new tab whose attach succeeds before any navigation is Covered and its zone and geolocation are sent once, with no extra sends when the navigation commits (the replay is Chrome's, not ours).
6. **Audit**: the New Tab Page residual measurement now reports the miss count with the override in place, expected 0 in 20; the tab-created-onto-url measurement stays as it is.

The New Tab Page is `extension/newtab.html`: a title, a `<meta name="color-scheme">`, an empty body, no script, no stylesheet. Chrome focuses the omnibox on an extension New Tab Page; verify that in slice 1 by checking the page has no focused element.
